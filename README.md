## 📌 Project Overview

This project is a simple, responsive unit conversion tool that allows users to convert values between different length and weight units.

The interface follows a minimal, elegant design with a warm cream and beige colour palette.

## ✨ Features

- Length unit conversion
- Weight unit conversion
- Live conversion while typing
- From/To unit selection
- Unit swap functionality
- Accurate conversion calculations
- Results rounded to 4 decimal places
- Conversion factor display
- Responsive mobile design
- Clean and minimal user interface
- No external libraries required

## 📏 Supported Length Units

## ⚖️ Supported Weight Units

## ⚙️ How It Works

1. Select a conversion category.
2. Enter a value.
3. Select the source unit.
4. Select the target unit.
5. The result updates automatically.
6. Use the swap button to reverse the conversion.

## 🧮 Conversion Logic

The application converts the entered value into a base unit first and then converts the base value into the selected target unit.

For example:

1 kilometer = 1000 meters

The same approach is used for all supported units.
